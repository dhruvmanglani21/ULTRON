ULTRON / WINDOWS COMPANION

Desktop controls

Keep ULTRON running while you work. Use Ctrl + Alt + X to stop PC actions and dictation immediately.

When enabled, requested window titles and accessible control names are shared with your ElevenLabs agent to operate apps. App changes and WhatsApp sends show a local approval dialog. Desktop control starts disabled on each launch.

WhatsApp

Link your WhatsApp account by scanning the QR code in the WhatsApp window. Add names and full international phone numbers below. Duplicate names are rejected so voice commands have one clear recipient.

Saved contacts

First connect your ElevenLabs key in the main ULTRON window and activate voice. For dictation, say “start dictation”, focus an editable field, then speak. Say “Ultron stop dictation” to return to commands. Some apps expose few accessible controls; this version does not promise control of every app feature.

PC commands disabled.
Allows requested app controls and dictation this session. Press Ctrl + Alt + E here to enable. Ctrl + Alt + X stops actions.
